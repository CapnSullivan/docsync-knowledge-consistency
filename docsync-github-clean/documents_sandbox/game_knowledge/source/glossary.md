# Источник знаний проекта

## Назначение документа

Этот документ описывает назначение центра знаний игрового проекта. Канонические значения хранятся в структурированном реестре `knowledge_registry.json`, а не внутри рабочих документов.

Markdown-документы должны оставаться чистыми рабочими материалами. Они могут содержать пояснения, описания, примеры и контекст, но не должны включать служебные конструкции системы анализа.

## Центр знаний

Основной источник структурированных данных:

```text
source/knowledge_registry.json
```

В этом файле хранятся ключи знаний, канонические значения, допустимые варианты написания и подозрительные варианты.

Примеры текущих ключей:

```text
game.title
game.short_description
term.mana
```

## Название игры

Каноническое название проекта хранится в `knowledge_registry.json` под ключом `game.title`.

Текущее значение:

```text
Game about of might and magik
```

Название игры является критически важным термином, потому что оно встречается во внутренних документах, UI-текстах, черновиках описания проекта и производственных заметках. Даже небольшие отличия в написании могут создавать путаницу.

## Короткое описание игры

Каноническое короткое описание хранится в `knowledge_registry.json` под ключом `game.short_description`.

Текущее значение:

```text
A tactical fantasy adventure about heroes, armies, spells, and ancient kingdoms.
```

Рабочие документы могут использовать сокращенные версии описания, но такие отличия должны попадать в отчет как кандидаты на проверку.

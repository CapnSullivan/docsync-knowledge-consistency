# DocSync — контроль согласованности документации

Учебный Python-проект для обнаружения расхождений в терминологии и формулировках, повторяющихся в нескольких документах. Прототип работает с демонстрационным набором игровой документации и JSON-реестром утверждённых терминов.

## Возможности

- Поиск канонических терминов, допустимых вариантов и подозрительных написаний в Markdown и DOCX.
- Поиск потенциальных опечаток по расстоянию Левенштейна и проверка похожих фраз.
- Отчёты с файлом, строкой и контекстом обнаруженного фрагмента.
- Выборочное исправление **Markdown** с проверкой исходного текста перед заменой.
- Консольное меню и локальный веб-интерфейс на FastAPI.
- Генерация воспроизводимых тестовых искажений с фиксированным `seed` и автоматические тесты.

## Структура

- `docsync/` — модели, чтение документов, сканирование, отчёты и применение исправлений.
- `Scripts/docsync_cli.py` — консольное управление.
- `Scripts/find_term_candidates.py` — сканер и точка входа для отчётов.
- `web_app/` — локальный веб-интерфейс на FastAPI.
- `documents_sandbox/game_knowledge/` — демонстрационный набор документов и JSON-реестр.
- `tests/` — тесты чтения DOCX и цикла поиска/исправления.

## Требования и установка

Python 3.11+ и `pip` (разработано в среде Python 3.11; другие версии требуют проверки совместимости).

В корне проекта (Windows PowerShell):

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Консольный режим

```powershell
.\.venv\Scripts\python.exe Scripts/docsync_cli.py
```

Для однократного сканирования:

```powershell
.\.venv\Scripts\python.exe Scripts/find_term_candidates.py
```

## Веб-интерфейс

Запустить `start_web_app.bat` или выполнить:

```powershell
.\.venv\Scripts\python.exe -m uvicorn web_app.app:app --host 127.0.0.1 --port 8010
```

Открыть `http://127.0.0.1:8010/` в браузере. Веб-приложение рассчитано на локальное использование, **не** на публичный сервер.

## Тесты

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тест полного цикла меняет только файлы демонстрационной песочницы и восстанавливает их после выполнения.

## Ограничения

- Сканер использует фиксированный демонстрационный каталог и реестр; произвольную папку через CLI пока задать нельзя.
- DOCX поддерживается **только для чтения и анализа**. Автоисправления применяются только к Markdown.
- Поиск по совпадениям и эвристикам может давать ложные срабатывания; результаты требуют проверки человеком.
- В текущем прототипе нет совместной работы пользователей, фонового слежения за изменениями файлов или двусторонней синхронизации документов.

Это прототип для проверки концепции, а не готовая промышленная система управления документацией.
